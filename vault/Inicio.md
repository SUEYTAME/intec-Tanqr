Índice del vault del proyecto **Plataforma de Tickets Digitales de Combustible — INTEC**.

Si eres un agente, el punto de entrada no es este archivo sino `AGENTS.md`, en la raíz del
repositorio. Este índice es para navegar desde Obsidian.

## Regla al añadir una nota

Toda nota nueva se enlaza aquí. Una nota fuera del índice es una nota que se pierde.
